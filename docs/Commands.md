# Launcher Commands

The launcher is a quick way to navigate Taskroot and manage your tasks and events. You can open it and start typing commands.

## Dynamic Commands

These commands take arguments to perform actions on tasks and events:

- **`plan <task name>`**
  - **Plan new task:** Creates and plans a new task with the given name.
  - **Plan existing task:** Plans an existing task that matches the query.

- **`do <task name>`**
  - **Do new task:** Creates a new task and immediately starts doing it.
  - **Do existing task:** Starts doing an existing task that matches the query.

- **`add <task name>`**
  - **Add new task:** Adds a new task to your list without scheduling it.

- **`sked`**
  - **View Schedule:** Shows up to 10 of your upcoming scheduled events for today.

## Static Commands & Navigation

You can also type these keywords to quickly jump to different parts of the app:

- **`plan`**: Navigate to the Plan screen.
- **`do`**: Navigate to the Do screen.
- **`docs`**, **`help`**, **`info`**: Open the Help/Docs screen.
- **`minitracker`**, **`tracker`**, **`timer`**, **`clock`**: Reset and show the Mini Tracker window.
